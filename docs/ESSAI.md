Version d'essai, non signée : Windows peut demander une confirmation au premier lancement.

Ouvrez le fichier téléchargé, puis Installer. Pour désinstaller : Paramètres › Applications
installées.

- Zone : Impr. écran (ou Ctrl + Maj + 1), glisser, relâcher : la zone est dans le presse-papiers.
- Écran : Ctrl + Maj + 2 : tout l'écran sous la souris est dans le presse-papiers.
- Fenêtre : Ctrl + Maj + 3, clic sur la fenêtre entourée de bleu : elle est dans le presse-papiers, coins arrondis compris.
- Refaire la dernière zone : Ctrl + Maj + 4 (ou le menu de l'icône) : la même zone, sans
  rien tracer. Sans zone depuis le lancement, ou si l'écran a changé, la sélection s'ouvre.
- Pipette de couleur : Ctrl + Maj + C (ou le menu de l'icône / la barre de capture) : l'écran
  se fige avec une loupe 15 × 15 pixels. Un clic (ou Entrée) copie le code couleur dans le
  presse-papiers ; molette, Tab, C ou F change le format (#RRGGBB, rgb(), hsl()) ; les flèches
  déplacent le viseur pixel par pixel.

Enregistrer dans Images › BreezyShot : bouton « Enregistrer » de la vignette, ou par le réglage.

Épingler à l'écran : bouton « Épingler » de la vignette, de l'éditeur ou de l'historique. La
capture s'ouvre dans une fenêtre flottante sans cadre, toujours au premier plan (12 au maximum) :
déplaçable à la souris, redimensionnable à la molette, opacité réglable (Alt + molette, de 25 % à
100 %), réinitialisable par la touche 0, copiable (Ctrl + C ou bouton au survol) et fermable au
double-clic, par Échap ou la croix au survol.

Annoter : bouton « Annoter » de la vignette. En bas, le socle : Annuler, Rétablir, les
outils (flèche, forme, texte, numéro, stylo, surligneur, flou, projecteur, gomme) et Fond
(touche F), toujours à la même place ; les réglages de l'outil pris — ou du fond (dégradé,
couleur unie, marge, coins arrondis, ombre portée) — juste au-dessus. Courber une flèche :
tirer son point du milieu. La gomme efface là où elle passe. Recadrer : tirer un coin de
l'image. En haut : Fermer à gauche ; à droite Texte, Épingler, Glisser (s'attrape pour glisser
l'image vers une appli), Enregistrer (Ctrl + S, range l'image dans le dossier des captures sans rien
demander ; sa flèche : Enregistrer sous…, Ctrl + Maj + S, et Enregistrer en .breezy modifiable
avec la licence) et Copier (copie et ferme).

Échap ou clic droit annule. L'icône près de l'horloge (clic gauche ou droit) ouvre le menu au
pointeur, d'où Réglages et Quitter ; un second clic sur l'icône le ferme. Lancer BreezyShot à la
main (icône épinglée à la barre des tâches, menu Démarrer), qu'il soit déjà ouvert ou non, ouvre la
barre de capture en haut de l'écran (des pictogrammes seuls, le nom au survol) : Zone, Plein
écran, Fenêtre, Pipette de couleur, Retardateur (un clic déplie ses choix dans la barre), Capture
défilante, Vidéo, GIF, Réglages. Sans licence, Capture défilante, Vidéo et GIF restent visibles
mais éteints, avec une mention « Pro » ; un clic dessus ouvre Réglages › Général › Licence. Au
démarrage de Windows (« Démarrer avec Windows ») et après l'installation, BreezyShot démarre sans
l'ouvrir.

Réglages › Capture : retardateur (3, 5 ou 10 s ; Échap ou la croix l'annule), Inclure le
pointeur dans l'image, Masquer les icônes du bureau (pendant le plein écran et les vidéos/GIF,
restaurées automatiquement ensuite), son de capture (« Goutte »), ouvrir directement dans l'éditeur.

Réglages (menu de l'icône, « Réglages ») : rubriques dans le volet de gauche. Copie, format
d'image (PNG, JPG ou WebP), dossier, nom des fichiers, raccourcis (cliquer puis taper le
nouveau), thème, lancement au démarrage de Windows. Dans **Raccourcis**, deux listes dédiées
sous Windows 11 — **Touche Impr. écran** et **Raccourci Win + Maj + S** — permettent de
choisir entre **l'Outil Capture de Windows** et **BreezyShot** (Zone, Barre de capture, Plein
écran, Fenêtre, Pipette, etc.). Tout s'applique tout de suite.

Licence (0.5) : Réglages › Général, dernière ligne « Licence » : coller la licence, puis
« Activer ». La licence d'essai est dans le fichier `essais/licence-essai.txt`. La ligne dit
alors « Pro activé » ; « Retirer » l'enlève. Sans redémarrer. Sans licence : ni historique,
ni Copier le texte, ni capture défilante, ni vidéo, ni GIF.

Avec la licence :

- Historique : Ctrl + Maj + H (ou « Historique » dans le menu de l'icône) : les 50 dernières
  captures. Copier, Enregistrer, Annoter, Épingler, Supprimer (Ctrl + Z l'annule pendant 5 s),
  glisser une capture vers une appli ; « Plus d'options » : Tout effacer.
- Copier le texte : Ctrl + Maj + T (ou le menu de l'icône), glisser autour du texte,
  relâcher : le texte est dans le presse-papiers. Dans l'éditeur : bouton « Texte », choisir
  les mots, « Copier » ou « Tout copier ». Le texte est lu dans les langues installées dans
  Windows ; sans aucune, Copier le texte n'apparaît pas.
- Capture défilante : Ctrl + Maj + 5 (ou le menu de l'icône), cliquer sur la page ou tracer
  une zone : la page défile seule, l'aperçu grandit à côté. Un cran de molette reprend la
  main. Fin seule en bas de la page (ou à 16 384 px), par « Terminer » ou Entrée ; Échap
  annule. L'image est dans le presse-papiers, comme une capture de zone.
- Vidéo et GIF : Ctrl + Maj + 6 (vidéo) ou Ctrl + Maj + 7 (GIF), ou le menu de l'icône,
  puis tracer une zone : l'enregistrement part. « Pause » et « Arrêter » sous la zone ; le
  même raccourci arrête aussi. Pour une vidéo, le bouton « Micro » ajoute le son du micro
  (coupé au début de chaque film). Le fichier va dans Images › BreezyShot ; la vignette le
  copie ou l'ouvre. Si l'app est fermée de force pendant un film, ce film est perdu.

Revenir à une version d'avant la 0.7 (réglages en version 6) : les réglages ne s'enregistrent plus. Supprimer
`%APPDATA%\BreezyShot\reglages.json` pour repartir.

Le journal : `%LOCALAPPDATA%\BreezyShot\Journal\breezyshot.log`.
